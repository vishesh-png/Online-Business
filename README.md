# Allo — Online Business

Online Business Summary tracker: Online SC (Months/Weeks/Days), Booking Summary
and D2P Summary per doctor — Utilisation, Capping, Revenue (New Online),
appointment funnel with joined splits, and D2P with diagnosis splits.

Access is password-protected. Built from the local `allo-bi/online-business-tracker/`
pipeline (`refresh.sh` + `build_deploy.sh`); this repo only ever holds the
encrypted page.
